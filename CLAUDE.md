# FilmScript — project rules

- **Design source of truth:** Before making any UI, layout, interaction, or visual change, read `/Users/franciscosagastume/Desktop/Filmscript/design/FILMSCRIPT_DESIGN_SYSTEM.md` in full and inspect `/Users/franciscosagastume/Desktop/Filmscript/design/02DFDABF-7EB3-4FDC-950B-B56E3BC1BE94.PNG`. Follow them over ad hoc visual choices.
- Before approving a visual change, apply the checklist in the design system, including accessibility, responsive behavior, light mode, and dark mode.

- **Never use dashes in copy.** No em-dashes (—), en-dashes (–), or hyphens as punctuation/connectors in any visible text. Rewrite sentences to avoid them.
- **The landing/Home page must always be Apple-inspired**: generous whitespace, large bold Helvetica headlines, centered sections, restrained palette, minimal.
- Hand-drawn theme stays throughout, but **subtle**, not heavily marked.
- **Approved card signature:** use a smooth double hand-drawn frame with two close, slightly different organic outlines. Corners should be soft and asymmetric, with restrained yellow line icons. Keep the interior alignment precise and never use noisy distortion.
- UI chrome/navigation uses Helvetica. Courier Prime only inside the screenplay page. Caveat reserved for occasional accent words.
- AI assistant is named **Lumiere** (no accent). It does not write for the user; it refines.
- Pricing: $20/mo with Lumiere, $10/mo without Lumiere.
